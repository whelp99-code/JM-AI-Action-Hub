오늘 이 대화에서 저는 이 프로젝트에 자동 검사원을 한 명 고용해 붙였습니다. 전에는 사람이 직접 기억해서 검사를 돌려야 했고, 깜빡하면 잘못된 상태가 그냥 통과했습니다. 실제로 그렇게 새어 나간 문제를 하나 발견해서 고쳤고, 이제는 누가 무엇을 고치든 자동으로 검사가 돌아가서 문제가 있으면 즉시 걸립니다.

잘 모르겠으면 "어떻게 시키면 좋을지 너가 다듬어 줘"라고 하셔도 됩니다. 제가 질문을 정리해서 되물어 드립니다.

제가 지키는 원칙

신뢰할 수 있어야 시킬 수 있으니까요.

확인 먼저 메일 발송, 외부 공개, 지우기처럼 되돌리기 어려운 일은 하기 전에 여쭙습니다. 오늘도 브랜치를 지우기 전에 먼저 여쭤봤고, 지울 때는 복구용 번호를 남겨 뒀습니다.
증거 있는 완료 실제로 돌려보고 결과를 본 뒤에만 "됐습니다"라고 말합니다. 안 해 본 건 "이건 확인 못 했습니다"라고 그대로 말씀드립니다.
실패도 그대로 안 되면 안 됐다고 말하고 실제 오류 내용을 보여드립니다. 얼버무리지 않습니다.

못 하는 것, 조심하는 것

과장하지 않고 말씀드립니다.

  • 비밀번호를 대신 입력하는 로그인은 제가 못 합니다. 그때는 직접 해 주십사 부탁드립니다.
  • 돈이 나가는 일, 남에게 나가는 연락은 반드시 먼저 보여드리고 허락을 받습니다.
  • 제가 틀릴 수 있습니다. 그래서 중요한 건 근거와 출처를 같이 드립니다. 확인해 주세요.
  • 대화를 새로 시작하면 앞의 맥락은 잊습니다. 계속 기억해야 할 건 "이건 기억해 둬"라고 말씀해 주시면 저장해 둡니다.
